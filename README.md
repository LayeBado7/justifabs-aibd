# JustifAbs AIBD SA — Version professionnelle

Application interne de gestion et de suivi des justificatifs d’absence.

## Évolutions intégrées
- logo officiel AIBD SA intégré automatiquement dans l’image Render ;
- charte graphique professionnelle et interface responsive ;
- page de connexion institutionnelle ;
- administration des comptes ;
- désactivation et réactivation ;
- suppression sécurisée ;
- protection du propre compte et du dernier administrateur ;
- conservation de la traçabilité par désactivation des comptes liés à un historique.

## Mise à jour GitHub / Render
Téléversez tous les fichiers de cette archive à la racine du dépôt GitHub, puis lancez **Manual Deploy > Clear build cache & deploy** dans Render.
Le fichier `embedded_assets.py` contient les pages, le style et le logo : aucun sous-dossier n’est requis lors du téléversement mobile.
